# Mathematik-Tools

Übungstrainer für den Mathematikunterricht. Jeder Trainer ist eine einzelne HTML-Datei (`index.html`) in einem eigenen Ordner, sortiert nach Lernumgebung.

| Lernumgebung | Trainer | Ordner |
| --- | --- | --- |
| Runden | Zahlen runden Trainer | `lu-runden/zahlen-runden/` |
| Masseinheiten | Masseinheiten Trainer | `lu-masseinheiten/masseinheiten/` |
| Brüche | Brüche Trainer | `lu-brueche/brueche/` |
