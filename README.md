# Mathematik-Tools

Übungstrainer für den Mathematikunterricht. Pro Lernumgebung (LU) gibt es einen Ordner mit einer einzelnen HTML-Datei (`index.html`). Die Adresse eines Trainers entspricht dem Ordnernamen, zum Beispiel `…/lu-c-brueche/`.

| Lernumgebung | Trainer | Ordner |
| --- | --- | --- |
| LU A Funktionen | – | `lu-a-funktionen/` |
| LU B Grössen | Masseinheiten Trainer | `lu-b-groessen/` |
| LU C Brüche | Brüche Trainer | `lu-c-brueche/` |
| LU D Zahlen | Zahlen runden Trainer | `lu-d-zahlen/` |
| LU E Dezimalzahlen | Komma Trainer | `lu-e-dezimalzahlen/` |
| LU F Konstruktionen | – | `lu-f-konstruktionen/` |
| LU G Koordinaten | – | `lu-g-koordinaten/` |
| LU H Terme | – | `lu-h-terme/` |

| LU K Diagramme | – | `lu-k-diagramme/` |
| LU L Zufall | – | `lu-l-zufall/` |
| LU M Zweidimensional | – | `lu-m-zweidimensional/` |
| LU N Dreidimensional | – | `lu-n-dreidimensional/` |
| LU O Strecken, Flächen, Volumen | – | `lu-o-strecken-flaechen-volumen/` |
| LU P Einführung Gleichung | – | `lu-p-einfuehrung-gleichung/` |
