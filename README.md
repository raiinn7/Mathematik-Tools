# Mathematik-Tools

Übungstrainer für den Mathematikunterricht. Jeder Trainer ist eine einzelne HTML-Datei (`index.html`) in einem eigenen Ordner, sortiert nach Lernumgebung (LU).

| Lernumgebung | Trainer | Ordner |
| --- | --- | --- |
| LU B Grössen | Masseinheiten Trainer | `LU B Grössen/masseinheiten/` |
| LU C Brüche | Brüche Trainer | `LU C Brüche/brueche/` |
| LU D Zahlen | Zahlen runden Trainer | `LU D Zahlen/zahlen-runden/` |
| LU E Dezimalzahlen | Komma Trainer | `LU E Dezimalzahlen/komma/` |

Die übrigen Lernumgebungen (A, F–H, J–R) sind als Ordner angelegt und warten auf ihre Trainer.
